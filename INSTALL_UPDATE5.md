## Что появилось
1. ❤️ /admin/score-explained — полное описание модели скора (пункт меню «Скор»)
2. Слои (bot/score_layers/): шум −6..0 (OSM магистрали), школы 0..+5 (OSM),
   банки (заглушка). Считаются для топ-10 объявлений с координатами за цикл,
   OSM кешируется 60 дней. Выключатель: настройка OSM_LAYERS.
   Бонус слоёв виден бейджем в Топ-10 и учитывается в сортировке.
3. market_type: primary/secondary (по году 2026+/«от застройщика»), бейдж в Топ-10.
4. AI-анализ текста (DeepSeek): выключен по умолчанию. Включить:
   - убедись что DEEPSEEK_API_KEY есть в .env
   - UPDATE app_settings SET value='1' WHERE key='AI_TEXT_ANALYSIS';
   Обрабатывает топ-10 объявлений с описанием за цикл, результат в карточке
   объекта (блок «AI-анализ описания»): срочность, дефекты, зацепки для торга.
5. korter_import.py — обогащение ЖК классом/застройщиком:
   venv/bin/python korter_import.py --test   # сначала посмотреть
   venv/bin/python korter_import.py          # записать
   Если --test ничего не найдёт — пришли /tmp/korter.html (команда в логе).

## Обновление 5.1: korter_import.py переписан

Причина: старая версия искала JSON-блобы, которых на странице нет — Korter
рендерит данные прямо в HTML. Новая версия парсит реальную структуру ссылок
через BeautifulSoup (уже используется в проекте).

Важное ограничение, узнанное на практике: страницы 2+ общего списка (`?page=2`)
Korter грузит через JS/XHR — обычным GET их не получить, они отдают ту же
первую страницу. Работает: 4 страницы фильтра по классу жилья
(эконом/комфорт/бизнес/элит) — это ОТДЕЛЬНЫЕ server-rendered страницы,
каждая с ~15-20 ЖК. Итого скрипт соберёт ~60-80 уникальных ЖК (крупные
игроки: BI Group, NAK, Tumar Group, Beles, Aiva Group...) с классом,
застройщиком, районом и ценой/м² — не все 263, но статистически самые
важные для тебя (это либо активные застройщики, либо дорогой сегмент).

Полное покрытие всех 263 потребует Playwright/Selenium (запуск браузера
с JS) — отдельная задача, если этого будет мало.

Тестировал логику парсинга (дедупликация имени, извлечение застройщика,
района, цены) на синтетической разметке, повторяющей реальный текст со
страницы — но САМОГО HTML сайта у меня нет доступа проверить напрямую,
поэтому первый прогон `--test` на сервере — это первая реальная проверка.
Если он покажет 0 ЖК или мусорные данные — пришли мне вывод, поправлю
за один заход (скорее всего понадобится подстроить регулярки под нюанс
разметки, который я не мог предвидеть без сырого HTML).

Запуск:
```bash
cd ~/krisha_bot
venv/bin/python korter_import.py --test
```
