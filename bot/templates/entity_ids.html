⚙️ Как считается матчинг

Каждая связь источник→ЖК получает confidence из сигналов, которые реально удалось проверить: точное совпадение нормализованного имени — базовый сигнал (+{{ thresholds.w_name }}), гео-близость в пределах {{ thresholds.geo_radius_m|int }} м — сильный сигнал (+{{ thresholds.w_geo }}), совпадение застройщика — доп. сигнал (+{{ thresholds.w_developer }}). confidence ≥ {{ thresholds.auto }} — связь пишется в спайн автоматически; {{ thresholds.review }}–{{ thresholds.auto }} — попадает в очередь на ручную проверку (сейчас — на странице переназначения ЖК); ниже {{ thresholds.review }} — связь не создаётся вовсе. Первый источник, принёсший новый ЖК (а не совпавший с уже существующим), пишется с confidence 1.0 — там неоднозначности нет, это и есть происхождение объекта (seed_source).
