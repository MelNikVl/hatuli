❤️ Скор: из чего он состоит
ИТОГ = Базовый скор (0–100) + Отделка (−5…+6, внутри базы) + Зоны (0…+20) + Слои (−6…+7)

1. Базовый скор — 100 баллов, 7 компонентов

КомпонентВесКак считается
Yield20Аренда из rental_index (уровень: ЖК+комнаты → район+комнаты → город+комнаты) × 12 / цена. Если продаёт риелтор — к цене прибавляется его комиссия (1%, мин 400к). ≥13% → 20 баллов, ≥10% → 15, ≥8% → 10, ≥5% → 5, меньше → 2.
Цена vs рынок15Цена/м² против медианы реальных аналогов (район + комнаты + площадь ±15%, доверяем от 5 шт). Fallback — медиана района. Ниже рынка на 15%+ → 15 🔥, на 5–15% → 10, в рынке → 5, дороже → 2.
Локация20Район: Есиль 20, Алматинский 16, Сарыарка 12, Байконур 10, Нура 8, не определён 5. Плюс до +3 за POI в тексте (ТРЦ, БЦ, университет, EXPO, Хан Шатыр, LRT...).
Тип квартиры151к → 15 (макс спрос), 2к → 13, 3к → 8, 4к+ → 4. Штрафы за метраж: 70м²+ → −2, 100м²+ → до −6. Оптимум 35–55 м².
ЖК (год)152022+ → 15, 2018+ → 11, 2012+ → 7, старше → 4, год неизвестен → 5. TODO: сюда просится застройщик, УК, отзывы, ликвидность ЖК.
Этаж82–7 этаж → 8 (оптимум), предпоследний → 5, последний → 1, первый → 0, не указан → 4.
Supply7Конкуренция в том же ЖК: 1–2 объявления → 7 (дефицит), 3–5 → 4, больше → 1.

2. Отделка −5…+6 (правит базовый скор)

Определяется по ключевым словам заголовка и описания: черновая −5, требует ремонта −4, предчистовая −2, чистовая +3, свежий ремонт +4, с мебелью +5, дизайнерский ремонт +6. При включённом AI-анализе (DeepSeek) отделка уточняется по смыслу текста.

3. Зоны приоритета 0…+20

Полигоны, которые ты рисуешь мышкой на карте зон (Ботсад, Туран, Мангилик...). Объявление с координатами внутри зоны получает назначенный бонус. Максимальный из пересекающихся зон.

4. Слои −6…+7

Независимые модули-поправки (bot/score_layers/), каждый можно включать/выключать и развивать отдельно. Считаются для объявлений с координатами, данные из OSM кешируются на 60 дней.

СлойДиапазонЛогика
🔊 Шум−6…0Магистраль (motorway/trunk/primary) в <100м → −6, в <250м → −4; оживлённая улица (secondary) в <100м → −3, в <250м → −1. Тишина — норма, не бонус. Внутренний шум (звукоизоляция) — в вопросах продавцу.
🏫 Школы0…+5Школа + садик в 700м → +5 (семейная локация), одно из двух → +3, только вуз → +2 (аренда студентам). Рейтинг заведений — следующий шаг.
🏦 Банки0 (заглушка)Задел: попадание под госпрограммы (7-20-25, Отбасы, Наурыз), залогопригодность, дельта льготной ставки. Ждёт парсер ставок.

Планируемые слои: планировка (распашонка/линейка — из AI-анализа), стороны света и вид (по ориентации дома в OSM), квартир на этаже / лифты, паркинг, ликвидность ЖК (из архив-статистики), новости по ЖК.

5. Первичка vs вторичка

Объявления делятся на primary (дом 2026+, «от застройщика», «сдача в...») и secondary. Пока обе ветки скорятся одной моделью, но у первички yield фиктивный (аренды ещё нет) — её скор надо читать как «потенциал». Отдельная модель первички (застройщик + стадия + дельта к готовым домам класса) — в работе, наполнится данными с korter.kz.

Куда смотреть в интерфейсе

В Аналитике — breakdown базового скора по компонентам. В Топ-10 — бейджи зон, слоёв и первички. В карточке объекта — причины скора, торг и вопросы продавцу. Ставки и параметры модели крутятся ползунками в Настройках.
