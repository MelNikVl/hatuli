❤️ Скор: из чего он состоит
ИТОГ = Базовый скор (0–100) + Отделка (−5…+6, внутри базы) + Зоны (0…+20) + Слои (−6…+14)

1. Базовый скор — 100 баллов, 7 компонентов

КомпонентВесКак считается
Yield20Аренда из rental_index (уровень: ЖК+комнаты → район+комнаты → город+комнаты) × 12 / цена. Если продаёт риелтор — к цене прибавляется его комиссия (1%, мин 400к). ≥13% → 20 баллов, ≥10% → 15, ≥8% → 10, ≥5% → 5, меньше → 2.
Цена vs рынок15Цена/м² против медианы реальных аналогов (район + комнаты + площадь ±15%, доверяем от 5 шт). Fallback — медиана района. Ниже рынка на 15%+ → 15 🔥, на 5–15% → 10, в рынке → 5, дороже → 2.
Локация20Район: Есиль 20, Алматинский 16, Сарыарка 12, Байконур 10, Нура 8, не определён 5. Плюс до +3 за POI в тексте (ТРЦ, БЦ, университет, EXPO, Хан Шатыр, LRT...).
Тип квартиры151к → 15 (макс спрос), 2к → 13, 3к → 8, 4к+ → 4. Штрафы за метраж: 70м²+ → −2, 100м²+ → до −6. Оптимум 35–55 м².
ЖК (год)152022+ → 15, 2018+ → 11, 2012+ → 7, старше → 4, год неизвестен → 5. TODO: сюда просится застройщик, УК, отзывы, ликвидность ЖК.
Этаж82–7 этаж → 8 (оптимум), предпоследний → 5, последний → 1, первый → 0, не указан → 4.
Supply7Конкуренция в том же ЖК: 1–2 объявления → 7 (дефицит), 3–5 → 4, больше → 1.

2. Отделка −5…+6 (правит базовый скор)

Определяется по ключевым словам заголовка и описания: черновая −5, требует ремонта −4, предчистовая −2, чистовая +3, свежий ремонт +4, с мебелью +5, дизайнерский ремонт +6. При включённом AI-анализе (DeepSeek) отделка уточняется по смыслу текста.

3. Зоны приоритета 0…+20

Полигоны, которые ты рисуешь мышкой на карте зон (Ботсад, Туран, Мангилик...). Объявление с координатами внутри зоны получает назначенный бонус. Максимальный из пересекающихся зон.

4. Слои −6…+14

Независимые модули-поправки (bot/score_layers/), каждый можно включать/выключать и развивать отдельно. Считаются для объявлений с координатами, данные из OSM кешируются на 60 дней.

СлойДиапазонЛогика
🔊 Шум−6…0Магистраль (motorway/trunk/primary) в <100м → −6, в <250м → −4; оживлённая улица (secondary) в <100м → −3, в <250м → −1. Тишина — норма, не бонус. Внутренний шум (звукоизоляция) — в вопросах продавцу.
🏫 Школы0…+5Школа + садик в 700м → +5 (семейная локация), одно из двух → +3, только вуз → +2 (аренда студентам). Рейтинг заведений — следующий шаг.
🚌 Транспорт0…+33+ остановок в 400м → +3 (узел), остановка в 400м → +2, в 700м → +1, ничего → 0 (машинозависимая локация).
🛒 Сервисы0…+4Walkability по мотивам Walk Score: супермаркет в 300м → +2, аптека/клиника в 500м → +1, 2+ кафе → +1.
🌳 Парки0…+2Парк/сквер в 400м → +2, в 700м → +1.
🏦 Банки0 (заглушка)Задел: попадание под госпрограммы (7-20-25, Отбасы, Наурыз), залогопригодность, дельта льготной ставки. Ждёт парсер ставок.

Penalty-правило сочетаемости (мировая практика — Local Logic, Walk Score): при шуме ≤ −4 бонусы школ и парков режутся вдвое — школа у магистрали не равна школе в тихом дворе. Разбор всех слоёв виден в карточке каждого объекта.

Калибровка весов по данным (гедонический подход Zillow/JLL): скрипт calibrate_location.py строит регрессию цена/м² ~ факторы на нашей же базе и показывает реальный вклад каждого слоя в тенге — веса подстраиваются по данным, а не «из головы». Требует ≥150 объявлений со слоями (копятся с 12.07).

Планируемые слои: планировка (распашонка/линейка — из AI-анализа), стороны света и вид (по ориентации дома в OSM), квартир на этаже / лифты, паркинг, ликвидность ЖК (из архив-статистики), новости по ЖК.

4¼. Продавец и зоны +5 / −20

От собственника: +5. Объявление без риелторской комиссии и с прямым контактом — выгоднее при той же цене. Определяется по пометке «хозяин недвижимости» на Крыше.

Вне зон: −20. Если на карте нарисованы зоны приоритета, объект с координатами, не попавший НИ в одну зону, получает штраф −20 — фокус выборки жёстко смещается в выбранные локации. Работает только когда зоны есть; объекты без координат не штрафуются (сначала докачка).

4½. Гексагон-анализ цены −8…+8

Город покрыт виртуальной гексагональной сеткой (ребро настраивается, дефолт 50 м). Для каждой квартиры считается ожидание локального рынка: медиана цены/м² в её гексагоне (вес 1.0, если там ≥3 объявлений), в 6 соседних (вес 0.7, если ≥5) и по городу (вес 0.35) — только среди квартир той же комнатности. Deal Index = ожидание / факт: DI 1.15 = на 15% дешевле микрорынка. Поправка к скору: (DI−1)·40, обрезано в ±8. Это микроуровень — районный компонент цены остаётся как макроуровень. Разбор виден в карточке объекта (блок ⬡).

5. Первичка: отдельная модель (100 баллов)

У первички нет сегодняшнего yield — базовая модель на 20% состоит из аренды, которой физически ещё нет. Поэтому объекты с market_type='primary' скорятся ОТДЕЛЬНОЙ моделью, полностью заменяющей базовый скор:

КомпонентВесЛогика
Застройщик30Крупный подтверждённый (BI Group, NAK, BAZIS-A и др. из справочника Korter) → 30, застройщик известен но без данных → 18, не определён → 10.
Стадия строительства20Сдан → 20, сдача через год → 14, через 2+ года → 8, котлован/старт продаж → 5 (риск переноса сроков).
Дисконт к вторичке30Сравнение цены/м² с медианой ВТОРИЧКИ того же района и похожей площади из нашей базы. 15-40% дешевле → 30 (здоровый дисконт за ожидание), 5-15% → 20, почти как вторичка → 10, дороже вторички → 5 (потенциал уже в цене), >40% дешевле → 15 (подозрительно, проверять риски).
Локация20Веса районов как в базовой модели.

Данные о застройщике приходят из обогащения ЖК (Korter/Homsters) — качество скора первички растёт по мере накопления справочника complexes. Разбор виден в карточке каждого объекта первички.

Куда смотреть в интерфейсе

В Аналитике — breakdown базового скора по компонентам. В Топ-10 — бейджи зон, слоёв и первички. В карточке объекта — причины скора, торг и вопросы продавцу. Ставки и параметры модели крутятся ползунками в Настройках.
