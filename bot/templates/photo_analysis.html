⚙️ Частота анализа
Работает по таймеру (krisha-floorplan.timer, каждые ~20-30 мин). За раз обрабатывает N объявлений ниже, с паузой между скачиванием фото — крутить можно прямо здесь, без правки systemd-юнита. Сейчас в очереди: {{ floorplan_queue }} объявл.
🤖 Какая модель работает и как
Гибрид: эвристика OpenCV (фильтр) → SigLIP (подтверждение). Эвристика отсекает ~90% фото (цветные интерьеры, фасады), SigLIP запускается только на ч/б-кандидатах.
МодельSigLIP ViT-B-16 (open_clip, веса webli) — мультимодальная модель OpenAI-CLIP-архитектуры: картинка и текст попадают в одно эмбеддинг-пространство, близость = семантическое сходство
Где работаетЛокально на сервере (CPU, ~/floorplan-clip/venv), без API и без оплаты за каждый вызов — модель скачана один раз (~450 МБ)
Как определяет планДля каждого фото считается сходство с 8 текстовыми описаниями: 4 «плана» (floor plan, architectural drawing, blueprint, top-down layout) и 4 «интерьера» (living room, kitchen, bedroom, interior photo). Через softmax получаются вероятности; фото = план, если макс. вероятность «плана» выше макс. вероятности «интерьера» и выше порога 0.22
ПроцессСкрипт floorplan_scan.py: берёт активные объявления с фото → качает фото с CDN Крыши (пауза 1 сек между загрузками, кэш по хешу URL) → классифицирует → пишет в listing_floorplans (скоры) + floorplan_url в объявление. Возобновляется с места остановки
