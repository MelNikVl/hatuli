## Продажа

Экспортированы 90 приватных кандидатов из 22 178 строк штатной read-only командой.
Лично открыты **39** источников в обычном браузере этого компьютера, **29**
фотографий интерьера подтверждены визуально в свежих галереях. Издатель заново
прочитал каталог и опубликовал **24** прошедших объекта. Экспорт не публиковался
как готовая подборка; серверный браузер и скрытые запросы к Krisha не использованы.

Контракт `discounted_four_factors`: minimum_count=10, target_count=30,
required_strong_factors=4, minimum_discount_pct=3; бюджет до 100 млн ₸.
У каждой карточки ровно четыре независимых причины. Процент и сумма одной
скидки не считались разными основаниями. Качество ремонта, локация, отзывы,
интерьер сам по себе и число аналогов не использованы как преимущества.

Причины исключения из просмотренного: два удалённых источника, один архивный,
семь без подтверждённого интерьера, четыре с менее чем четырьмя основаниями,
один с противоречием потолков в плане и характеристике. У одного из четырёх
продавец в свежем источнике оказался специалистом; прежний owner-фактор снят.
Планы, фасады и общие холлы не сохранены как обложки. Неутверждённые старые
фото не наследовались. У каждого из 24 выбранных — одно точное URL из лично
просмотренной сегодняшней галереи, совпавший UUID/кадр сохранённой галереи,
photo_review.method=normal_browser_visual и одинаковый с source-check timestamp.

Проверки опубликованных источников: **08:08:10–08:19:09**, возраст при выпуске
2,74–13,72 минуты. Цена, комнаты, площадь, этаж/этажность и используемые кухня/
потолки сверены с источником. Роль хозяина — только видимая роль автора вместе
с существующим подтверждением каталога; это не проверка права собственности
или отсутствия комиссии. У `1014540534` структурно виден залог, пометка сохранена.

Идентичность: **21 catalog_bound + 3 source_address_only**. Это соответствие
существующим правилам, не независимый осмотр домов. У трёх источников отсутствует

## Приёмка

- Независимые offline-аудиты исходных квитанций, характеристик, цен, возраста,
  математики четырёх факторов и фотографий: ошибок/предупреждений нет.
- Публичные страницы без входа: HTTP 200, **24×4 и 18×4**, дата 18 октября,
  полный источник/цена/адрес, правильный месячный период аренды. Все **24**
  перехода в `/compare` сохраняют ID, цену, адрес, четыре причины и пометки;
  отметка залога не теряется, неверные mismatch-плашки не добавляются.
- Живой локальный браузер: desktop и **390×844**, без горизонтального выхода
  карточек/фото. Обложки используют contain, выбранные фото загружаются.
  В сегодняшних карточках по одному фото: дополнительные элементы галереи
  скрыты. Переключение продажи/аренды и переход из продажи в сравнение работают.
- Реальный график изменения цены `1015074964` и раскрытая таблица с датой,
  80 → 75 млн ₸ показаны на узком экране. До первой записи нет выдуманной
  истории. Прогнозы без готового численного артефакта скрыты вместе с блоками;
  плашек «недостаточно данных» нет. У аренды графиков без подтверждённой истории нет.

Изолированные тесты неизменённого кода заново не запускались. Production DSN,
init_pool, миграции и фикстуры для тестов не использовались. Штатные экспорт/
издатели читали PostgreSQL в read-only транзакциях; записи — только приватные
доказательства и атомарные JSON. Не применялись force, allow-partial, skip-photo-check,
ручная правка публичных снимков или изменение даты старых доказательств.
