## 2. exact/perceptual/semantic — НЕ взаимоисключающие категории

Скрипт печатает `category` как ПЕРВОЕ совпавшее по приоритету
(exact > perceptual > semantic > no_match) — это СВОДНАЯ метка для
прогресс-лога, НЕ факт "у пары есть только этот один тип совпадения".
Прямая проверка сырых per-candidate счётчиков (`exact`/`perceptual`/`ai`)
из `photo_evidence_priority_canary_result.json` даёt честную матрицу
пересечений:

| | exact>0 | perceptual>0 | ai(semantic)>0 |
|---|---|---|---|
| **exact>0** | 103 | 99 | 0 |
| **perceptual>0** | 99 | 351 | 1 |
| **ai>0** | 0 | 1 | 1 |

Диагонали — total с этим сигналом >0 (**exact: 103, perceptual: 351,
semantic: 1**, НЕ 103/252/0 из сводного `category`!). Недиагональные
ячейки — пересечения.

**Находка**: **99 пар (26% от всех 351 с perceptual>0) имеют И exact, И
perceptual совпадения одновременно** — часть фотографий пары совпала
побайтово (SHA256), другая часть — только perceptual (после
пережатия/ресайза). Сводная метрика `category='exact'` СКРЫВАЛА это —
такие пары считались только "exact" в прогресс-логе. **1 пара** имеет
одновременно perceptual И semantic (ai) сигнал.
