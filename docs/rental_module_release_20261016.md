  ручной расчёт безубыточности, явные расходы/налог, сценарии 45/60/75%,

- [Посуточный индекс](https://hatuli.ai-groundtruth.com/rental/daily): только
  готовые район × комнаты, диапазон, число источников, фактические даты
  и окно 30/90 дней. Нет готового среза — таблица целиком скрыта.
- Доходность в существующей карточке/аналитике/Buyer Bot: net, диапазон
  аренды, источник и допущения. Фильтры, сортировка и p90 работают по
  квалифицированным снимкам; первичка без доказанной готовности исключена.
- История сохраняет реальные наблюдения и эпизоды. Новая цена внутри дня
  обновляет индекс без переписывания первого дневного снимка. Снятие
  объявления не называется сдачей и не превращается в загрузку.
- Подписки доходности расширяют существующие searches/outbox Buyer Bot:
  confirmed property identity, дедуп, keyset без потери 201-й записи,
  дневной лимит по попыткам доставки и свежая проверка перед отправкой.
