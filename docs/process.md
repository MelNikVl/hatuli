# Процесс: параллельные сессии

Решение заказчика, 2026-08-13.

**Параллельные Claude-сессии над этим репо — только в отдельных git
worktree, никогда в общем рабочем дереве.** Причина: несколько сессий,
пишущих в один и тот же `krisha_bot/` одновременно, гонятся за одними
и теми же файлами (миграции, `app_settings`, скрипты гейтов) — молчаливая
потеря правок одной сессии другой, без конфликта, который было бы видно.
Worktree даёт каждой сессии свою копию файлов при общей истории git.

Существующие worktree сессий — под `.claude/worktrees/` (см. `git worktree
list`), заводятся/чистятся автоматически инструментом сессии (`isolation:
"worktree"` у Agent-тула) либо вручную:

```bash
git worktree add .claude/worktrees/<name> <branch>
```

Не относится к однократным фоновым скриптам/крону (`hype_tracker/
krisha_complex_scan.py` и т.п.) — те не редактируют код репозитория,
только читают/пишут в БД, гонки там другого рода (транзакционные,
не файловые) и вне объёма этого решения.
