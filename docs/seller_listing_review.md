# Раздел «Что улучшить в объявлении»

Публичная страница `/improve-listing`, пункт общей навигации «Продавцу».
Пользователь вставляет текст и/или ссылку Krisha, при желании дополняет
параметры и отмечает состав фото. После POST видит до пяти приоритетных
исправлений, дополнительные рекомендации, фото-чеклист и основу описания.
Первый ответ сразу открывает результат; форма работает без JavaScript.

## Источники и доступ

Ссылка валидируется по домену и пути; запросов к произвольным URL нет.
Анониму доступны только уже опубликованные параметры свежей квартиры из
«Лучших вариантов». Подписчик с full_access и подтверждённый администратор
могут подставить свежую запись из существующей базы в пределах текущих прав.
Возраст источника ограничен 72 часами. Если доступного текста нет,
страница предлагает вставить собственное описание; пустой кеш не считается
доказательством недостатков объявления.

Выбираются только поля квартиры и текст, без контактов продавца, профилей,
координат и личных документов. Фотографии в публичной подборке являются
ограниченной выборкой: их число не выдаётся за полный состав объявления.
Изображения пока не анализируются; конкретные недостающие ракурсы выводятся
из отметок пользователя, неизвестные — как задачи для самопроверки.

Текст обрабатывается только для текущего ответа. Маршрут не сохраняет его
в БД, не редактирует исходное объявление и не вызывает внешнюю модель.
POST ограничен 128 KiB; текст — 12 000 символов. Формы экранируются,
дубли полей и неверные JSON отвергаются, ответы имеют no-store.

## Проверки и черновик

`bot/core/seller_listing_review.py` использует правила и явные числовые
характеристики. Цена извлекается только из подписи цены продажи в тенге;
общая площадь, кухня, потолки, этажность и год — из однозначных формулировок.
Противоречащие значения помечаются для проверки и исключаются из черновика.
Черновик создаётся из безопасной проекции фактов, а не повторяет исходный
текст. Контакты, ссылки и личные номера в него не переносятся.

Сведения об ипотеке и коммунальных расходах остаются словами продавца;
проверка прав собственности, отсутствия долгов и юридической чистоты
не выполняется. Рекомендации не обещают срок продажи или увеличение цены.

Основа рекомендаций — официальные руководства Krisha, Rightmove и Zillow,
ссылки приведены в методологии страницы. Количество фото и показатели
эффекта зарубежных рынков не переносятся в обещания для Астаны.

## Следующий этап с ИИ

Наибольшая дополнительная польза: классификация комнат и ракурсов,
повторяющиеся и неудачные кадры, выбор обложки. Каждый вывод должен ссылаться
на конкретное фото, показывать уверенность и позволять исправить результат.
Перед внешней обработкой необходимы отдельный понятный выбор пользователя,
удаление контактов и личных данных и проверка структурированного ответа.
Существующий общий AI-пайплайн с записью БД и уведомлениями не используется.

Проверки: `tests/test_seller_listing_review.py`,
`tests/test_seller_review_routes.py`, проверка полного пути формы в браузере
и экранов 390/320 px. Миграции и новые фоновые сервисы не требуются.
