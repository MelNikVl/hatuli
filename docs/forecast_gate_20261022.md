# Допуск прогноза: согласованность метрик — 22 октября 2026

## Источники и выбор

Проверено22.10.2026, без переноса чужих заявлений о точности на Hatuli:
- [Krisha: оценка](https://krisha.kz/valuation/) — параметры квартиры,
  похожие объявления, диапазон; точность зависит от введённых данных и аналогов.
  Это текущий продукт в Казахстане, а не новая статистика сделок.
- [Zillow Zestimate](https://www.zillow.com/zestimate/) — свойства объекта,
  источники, интервалы неопределённости и отдельная проверка точности.
  Это зарубежный пример прозрачности оценки, не доказательство нашей точности.

Вывод для Hatuli: качество исходных данных и проверяемые доказательства
готовности важнее дополнительного числа на карточке. Анализ репозитория выявил
конкретный дефект в общем passes_gate: заявленный процент улучшения мог
противоречить RMS log errors. Публичный runtime проверял диапазоны метрик,
но тоже принимал такой отчёт; например error .03 против baseline .02 вместе
с заявленным выигрышем50% пропускал опубликованный прогноз.

## Изменение

Общий допуск используется обучением, forecast_listing и публичным runtime.
Теперь требует конечные числовые метрики без bool/строк, целые counts/folds,
sample>=independent>=changed, прежние минимумы200/50 и2folds; RMS модели
неотрицателен и меньше положительного baseline. Реальный выигрыш не меньше5%,
заявленный совпадает с (1-error/baseline)*100 с допуском0,1 процентного пункта.
Допуск округления не позволяет пересечь порог5% с реальным выигрышем4,95%.
CI положителен и упорядочен, доли ограничены, ширина интервала>0 и<=40%,
номинальное покрытие80%. Некорректный отчёт отказывает в публикации чисел.
Метод обучения, целевые величины и минимальные пороги точности не заменялись.
